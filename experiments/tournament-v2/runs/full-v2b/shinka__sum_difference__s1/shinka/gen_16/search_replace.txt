relaxed_sidon_diff_collisions</NAME>

<DESCRIPTION>
The current program enforces strict Sidon-ness in `_bounded_sidon`, which forces all pairwise differences to be unique. This maximizes |A−A| but also inflates |A+A| because Sidon sets spread out over a wide span. The objective log|A−A|/log|A+A| rewards trading a small loss in |A−A| for a larger relative reduction in |A+A|.

Idea: relax the difference-uniqueness constraint in `_bounded_sidon` to allow a controlled fraction of duplicate differences (track a diff-multiplicity counter and permit up to ~20% collisions), while still rejecting any sum collision. This yields a denser set inside a tighter span, shrinking |A+A| while keeping |A−A| close to maximal. I add a `diff_budget` parameter proportional to n and a `diff_counts` dictionary to enforce it. The rest of the pipeline (quadratic sets, greedy Sidon, reflection, local search) is unchanged and still available; the new construction simply provides additional candidate sets that the existing scoring/local-search machinery can exploit. I also add a `sum_span` penalty bias so candidates near the center are preferred (already partially present), and ensure spans are tuned tighter (span_mult 2 and 3 dominate for the relaxed variant).

def _bounded_sidon(n, span, seed=0):
    """Build a Sidon-like set of size n inside [0, span] using randomized greedy,
    biased toward keeping elements near the middle (compacting the sum set)."""
    rng = random.Random(seed)
    A = []
    used_sums = set()
    used_diffs = set()
    # Prefer candidates near the center of the span to keep |A+A| small.
    center = span // 2
    cand = sorted(range(0, span + 1), key=lambda x: (abs(x - center), rng.random()))
    for x in cand:
        ok = True
        new_sums = set()
        new_diffs = set()
        for a in A:
            s = x + a
            if s in used_sums or s in new_sums:
                ok = False
                break
            new_sums.add(s)
            d1 = x - a
            d2 = a - x
            if d1 in used_diffs or d2 in used_diffs or d1 in new_diffs or d2 in new_diffs:
                ok = False
                break
            new_diffs.add(d1)
            new_diffs.add(d2)
        if ok:
            A.append(x)
            used_sums |= new_sums | {2 * x}
            used_diffs |= new_diffs
        if len(A) >= n:
            break
    return A

def _bounded_sidon(n, span, seed=0, diff_budget_frac=0.2):
    """Build a Sidon-LIKE set of size n inside [0, span] using randomized greedy,
    biased toward keeping elements near the middle (compacting the sum set).

    Difference collisions are allowed up to `diff_budget_frac` of the total
    pairwise differences, which lets the set be denser (smaller span for the
    same n) and thus shrinks |A+A|, at the cost of a small |A-A| loss. Sum
    collisions are still strictly forbidden.
    """
    rng = random.Random(seed)
    A = []
    used_sums = set()
    diff_counts = {}
    # Budget of allowed duplicate differences (collisions).
    diff_budget = max(1, int(diff_budget_frac * n * (n - 1) / 2))
    collisions = 0
    # Prefer candidates near the center of the span to keep |A+A| small.
    center = span // 2
    cand = sorted(range(0, span + 1), key=lambda x: (abs(x - center), rng.random()))
    for x in cand:
        ok = True
        new_sums = set()
        new_diffs = []
        local_collisions = 0
        for a in A:
            s = x + a
            if s in used_sums or s in new_sums:
                ok = False
                break
            new_sums.add(s)
            d1 = x - a
            d2 = a - x
            for d in (d1, d2):
                c = diff_counts.get(d, 0)
                if c >= 1:
                    local_collisions += 1
            new_diffs.append(d1)
            new_diffs.append(d2)
        if ok and collisions + local_collisions <= diff_budget:
            A.append(x)
            used_sums |= new_sums | {2 * x}
            for d in new_diffs:
                diff_counts[d] = diff_counts.get(d, 0) + 1
            collisions += local_collisions
        if len(A) >= n:
            break
    return A
