<DESCRIPTION>
The current program spends a large amount of time exhaustively enumerating Sidon constructions (quadratic sets, bounded Sidon sets, greedy Sidon sets) and keeps only the single best seed by the combined score (which includes the small size bonus). This wastes the exploration of many nearly-equivalent configurations and gives only one starting point for the 100-second local search.

The recommendation is to:
1. Separate the pure ratio `log|A-A|/log|A+A|` from the size bonus during seed selection, so seeds are ranked by the primary objective.
2. Collect the top-K (K≈20) distinct seeds by pure ratio instead of just the single best.
3. Run local search sequentially over these top-K seeds within the remaining time budget (still respecting the 110s deadline), so the highest-ratio seed gets the most refinement time, and diverse basins are explored.

This keeps the existing seed generators (quadratic, bounded Sidon, greedy Sidon) but changes the selection/refinement loop to be ratio-aware and top-K based. The size bonus is retained only as a tiebreaker.

Implementation details:
- Add a helper `_ratio(a)` that returns the pure log-ratio (or -inf for degenerate sets).
- Maintain a list `seeds` of (ratio, a) tuples collected from every generator.
- After generation, deduplicate seeds (by frozenset) and keep the top-K by ratio.
- Loop over the top-K seeds, allocating a share of the remaining time to each (e.g., proportional to rank), running the existing local search from each seed and tracking the best overall by `_score`.
- Keep the final polishing step on the overall best.

This targets the plateau at 1.13731 by starting refinement from the highest-ratio configurations rather than the first improving one, and by exploring multiple basins.

def _local_search(seed, deadline, best, best_score):
    """Run multi-scale local search from `seed` until `deadline`.
    Returns updated (best, best_score)."""
    cur = seed[:]
    cur_score = _score(cur)
    if cur_score > best_score:
        best, best_score = cur[:], cur_score
    span_cur = (max(cur) - min(cur)) if len(cur) > 1 else 1
    while time.time() < deadline:
        cand = cur[:]
        i = random.randrange(len(cand))
        if random.random() < 0.7:
            step = max(1, span_cur // 50)
        else:
            step = max(1, span_cur // 8)
        delta = random.randint(-step, step)
        if delta == 0:
            delta = 1
        cand[i] += delta
        cand = list(set(cand))
        if len(cand) < 2:
            continue
        s = _score(cand)
        if s >= cur_score:
            cur, cur_score = cand, s
            span_cur = (max(cur) - min(cur)) if len(cur) > 1 else 1
            if s > best_score:
                best, best_score = cand[:], s
        elif random.random() < 0.03:
            cur = cand
            span_cur = (max(cur) - min(cur)) if len(cur) > 1 else 1
    return best, best_score


def solve():
    """Return a list of distinct integers A making |A - A| large and |A + A| small."""
    # Collect a diverse pool of candidate seeds with their pure ratios.
    seeds = []  # list of (ratio, list)

    def _add(cand):
        r = _ratio(cand)
        if r > float("-inf"):
            seeds.append((r, list(cand)))

    # Try structured quadratic constructions for a range of primes.
    primes = [p for p in range(11, 200) if all(p % d for d in range(2, int(p ** 0.5) + 1))]
    for p in primes:
        cand = _quadratic_set(p)
        for shift in (0, -p // 2):
            _add([x + shift for x in cand])
        r = _reflect_half(cand)
        if len(set(r)) == len(cand):
            _add(r)

    # Bounded Sidon constructions inside a tight span.
    for n in [20, 40, 60, 90, 120, 160, 200]:
        for span_mult in (2, 3, 4, 6):
            span = n * n * span_mult
            if span > 10 ** 6:
                continue
            for seed in (n, n * 7 + 1, n * 13 + 5):
                cand = _bounded_sidon(n, span, seed=seed)
                if len(cand) >= 2:
                    _add(cand)

    # Greedy Sidon sets of various sizes.
    for n in [30, 50, 80, 120, 150]:
        cand = _greedy_sidon(n, seed=n)
        if len(cand) >= 2:
            _add(cand)

    if not seeds:
        seeds = [(_ratio([7, 15, 18, 22, -3, -2]), [7, 15, 18, 22, -3, -2])]

    # Deduplicate by frozenset, then rank by pure ratio (size bonus only as tiebreak).
    seen = set()
    uniq = []
    for r, a in sorted(seeds, key=lambda t: (-t[0], -len(set(t[1])))):
        key = frozenset(a)
        if key in seen:
            continue
        seen.add(key)
        uniq.append((r, a))

    # Keep top-K seeds by pure ratio for refinement.
    K = 20
    top = uniq[:K]

    # Initialize best from the highest-ratio seed by _score.
    best = None
    best_score = -1.0
    for r, a in top:
        s = _score(a)
        if s > best_score:
            best_score = s
            best = a[:]

    # Allocate remaining time across top-K seeds, weighted toward higher ranks.
    start = time.time()
    total_budget = 100.0
    # Weight: rank 1 gets the largest share.
    weights = [K - i for i in range(len(top))]
    wsum = sum(weights)
    elapsed = 0.0
    for idx, (r, a) in enumerate(top):
        share = total_budget * weights[idx] / wsum
        sub_deadline = start + elapsed + share
        best, best_score = _local_search(a, sub_deadline, best, best_score)
        elapsed = time.time() - start
        if elapsed >= total_budget:
            break
