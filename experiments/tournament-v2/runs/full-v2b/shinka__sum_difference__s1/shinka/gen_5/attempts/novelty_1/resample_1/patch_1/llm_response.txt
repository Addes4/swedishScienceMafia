The baseline random local search only finds small sets with a ratio near 1.14, while the best known is 1.28. A much better construction comes from additive combinatorics: sets with small sum set but large difference set are related to Sidon/B_h sets and Golomb rulers. In particular, for a Golomb ruler the difference set has all distinct positive values (|A-A| = n(n-1)+1, the maximum possible), giving log|A-A| ≈ 2 log n. Meanwhile, we can choose the ruler so that A+A is small.

A strong known family is the "Singer difference set" / modular Sidon construction: take a Sidon set S in Z_p (a perfect difference set of size q+1 when p = q^2+q+1), then the difference set covers all nonzero residues (|A-A| = p) while the sum set in integers can be kept small. Concretely, a Bose-Chowla Sidon set of size q+1 in Z_{q^2-1} has the property that all differences are distinct mod q^2-1, but as integers the set {0,1,3,7,...} (powers-of-2-like Sidon) is a classic example.

I'll implement a constructive approach: build a Sidon set via the Bose-Chowla construction using a finite field, then map it to integers. This guarantees |A-A| ≈ n^2 (near-maximal) while giving control over |A+A|. I'll also add a local-search polish step on top of the construction to reduce |A+A| further without breaking the difference-set size.

Concretely:
- Use the classic Sidon set {2^(2^i)} style? No — better: use the Erdos-Turan / Bose construction: for prime power q, the set { (x, x^2) mapped } gives Sidon. Simplest practical: pick a Sidon set of integers directly via a greedy Golomb-ruler-like construction that maximizes |A-A| and then run local search minimizing |A+A|.

I'll build a set whose difference set is essentially all distinct (Golomb ruler) — e.g. a known optimal Golomb ruler of order ~25 — which gives |A-A| = n(n-1)+1. Then apply local search that only accepts moves reducing |A+A| (while keeping the difference set large). This should push the ratio well above 1.14 toward ~1.28.

Implementation plan:
1. Construct a Golomb ruler greedily: start with {0}, repeatedly add the smallest integer that keeps all pairwise differences distinct.
2. Compute initial score.
3. Run local search that perturbs elements to reduce |A+A| while maintaining |A-A| close to n(n-1)+1 (accept moves that increase the ratio).
4. Increase time budget and set size (Golomb rulers of order 20-30 give large ratios).

I'll replace the whole solve() with this construction + targeted local search, and boost the deadline to ~100s.

import math
import random
import time


def _score(a):
    a = set(a)
    if len(a) < 2:
        return 0.0
    diffs = {x - y for x in a for y in a}
    sums = {x + y for x in a for y in a}
    return math.log(len(diffs)) / math.log(len(sums)) + (1 - 1 / len(a)) / 100

"""Constructive Sidon/Golomb-based sets with large difference set and small sum set."""
import math
import random
import time


def _score(a):
    a = set(a)
    if len(a) < 2:
        return 0.0
    diffs = {x - y for x in a for y in a}
    sums = {x + y for x in a for y in a}
    return math.log(len(diffs)) / math.log(len(sums)) + (1 - 1 / len(a)) / 100


def _golomb_ruler(n):
    """Greedy Golomb ruler: all pairwise differences distinct, so |A-A| = n(n-1)+1."""
    marks = [0]
    used = {0}
    candidate = 1
    while len(marks) < n:
        ok = True
        for m in marks:
            d = candidate - m
            if d in used:
                ok = False
                break
        if ok:
            for m in marks:
                used.add(candidate - m)
            marks.append(candidate)
        candidate += 1
    return marks


def _local_search(a, deadline, rng):
    a = sorted(set(a))
    best = a[:]
    best_score = _score(best)
    cur = a[:]
    cur_score = best_score
    while time.time() < deadline:
        cand = cur[:]
        n = len(cand)
        # perturb an element
        i = rng.randrange(n)
        cand[i] += rng.randint(-4, 4)
        if len(set(cand)) != n:
            continue
        cand = sorted(cand)
        s = _score(cand)
        if s > cur_score or (s == cur_score and rng.random() < 0.2):
            cur, cur_score = cand, s
            if s > best_score:
                best, best_score = cand[:], s
        elif rng.random() < 0.15:
            cur, cur_score = best[:], best_score
    return best


def solve():
    """Return a list of distinct integers A making |A - A| large and |A + A| small."""
    rng = random.Random(12345)
    deadline = time.time() + 100

    best = [7, 15, 18, 22, -3, -2]
    best_score = _score(best)

    # Try Golomb rulers of several orders; they maximise |A-A| = n(n-1)+1.
    for n in range(16, 34):
        if time.time() > deadline - 5:
            break
        base = _golomb_ruler(n)
        # center around zero to help sum set stay compact
        mid = base[-1] // 2
        base = [x - mid for x in base]
        s = _score(base)
        if s > best_score:
            best, best_score = base[:], s
        # local search polish
        polished = _local_search(base, min(deadline, time.time() + 4), rng)
        ps = _score(polished)
        if ps > best_score:
            best, best_score = polished[:], ps

    # final polish on the overall best
    if time.time() < deadline:
        final = _local_search(best, deadline, rng)
        fs = _score(final)
        if fs > best_score:
            best, best_score = final, fs

    return sorted(set(best))
