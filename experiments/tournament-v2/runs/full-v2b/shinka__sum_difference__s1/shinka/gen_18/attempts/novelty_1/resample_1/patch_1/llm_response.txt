<DESCRIPTION>
The current program fixes cardinality implicitly through the structured construction (m + gs) and lets SA drift the size. The size bonus `(1 - 1/n)/100` is tiny (~0.01 at n=100) yet the SA is biased toward whatever size the seed happens to have. Meanwhile, the pure log-ratio `log|A-A|/log|A+A|` can behave quite differently at different cardinalities: for dense intervals |A-A| ~ 2n and |A+A| ~ 2n giving ratio ~1, but for sparse Golomb-like sets |A-A| ~ n(n-1) while |A+A| stays much smaller, so larger n can help if we keep sums sub-quadratic.

I propose running the local search across a *range* of target cardinalities n ∈ {40, 60, 90, 130, 180, 250, 350, 500}, allocating time proportionally to the pure log-ratio (i.e. dropping the size bonus from the search objective so it doesn't distort the comparison). Allocate a fixed slice of the deadline to each n, always starting from a structured seed of exactly that size (dense core of size ~sqrt(n) plus Golomb tail of size n - core), and keep the best result across all n. This makes the search cardinality-aware and lets us discover whether a larger n actually improves the pure ratio, rather than letting SA wander in cardinality space.

Concretely:
1. Add a `_score_pure(a)` function that returns just `log|A-A|/log|A+A|` (no size bonus).
2. Add a `_build_of_size(n, rng)` helper that constructs a structured seed with exactly n elements: core = range(m+1) where m ≈ round(sqrt(n)), tail = Golomb of size n - m - 1 offset by m + gap, with gap and stride/scale chosen randomly.
3. Add a `_local_search_pure` variant that uses `_score_pure` (so the trajectory is not biased by the size bonus) and collects the best set found.
4. In `solve()`, loop over the target cardinalities, giving each one a time slice, and keep the overall best by `_score_pure`. Final returned set is the pure-ratio winner (the actual grading still adds the size bonus, which we accept as a small bonus on top).

This should let the search explore the cardinality axis directly, which the current program does only accidentally.

def _build_of_size(n, rng):
    """Build a structured seed with exactly n elements: dense core + Golomb tail."""
    if n <= 1:
        return [0]
    if n <= 4:
        return list(range(n))
    # core size close to sqrt(n) so that core sums/diffs stay small
    m = max(1, int(round(math.sqrt(n))) - 1)
    gs = n - (m + 1)
    if gs <= 0:
        return list(range(n))
    gap = rng.randint(1, 20)
    stride = rng.choice([1, 1, 1, 2, 3])
    scale = rng.choice([1, 1, 1, 2, 3])
    cand = _build_dense_golomb(m, gs, gap, rng, stride, scale)
    cand = sorted(set(cand))
    # pad/trim to exactly n
    if len(cand) < n:
        hi = max(cand)
        x = hi + 1
        while len(cand) < n:
            if x not in cand:
                cand.append(x)
            x += 1
        cand = sorted(set(cand))
    elif len(cand) > n:
        cand = sorted(cand)[:n]
    return cand

def solve():
    """Return a list of distinct integers A making |A - A| large and |A + A| small:
    maximise log|A - A| / log|A + A|."""
    rng = random.Random(987654321)
    deadline = time.time() + 110

    best = [7, 15, 18, 22, -3, -2]
    best_score = _score_fast(best)

    # Phase 0: cardinality-aware search over target sizes using the pure ratio.
    target_sizes = [40, 60, 90, 130, 180, 250, 350, 500]
    pure_best = None
    pure_best_score = -1.0
    phase0_end = time.time() + 55
    per_n = max(3.0, (phase0_end - time.time()) / max(1, len(target_sizes)))
    for n_target in target_sizes:
        if time.time() >= phase0_end:
            break
        # try a few random seeds of this size, then SA
        local_best = None
        local_score = -1.0
        for _ in range(3):
            if time.time() >= phase0_end:
                break
            seed = _build_of_size(n_target, rng)
            sub_end = min(phase0_end, time.time() + per_n / 3.0)
            cand, s = _local_search_pure(seed, sub_end, rng)
            if s > local_score:
                local_score = s
                local_best = cand
        if local_best is not None and local_score > pure_best_score:
            pure_best_score = local_score
            pure_best = local_best[:]

        s_full = _score_fast(pure_best)
        if s_full > best_score:

            best_score = s_full
