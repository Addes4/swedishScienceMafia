<DESCRIPTION>
The current local search perturbs elements randomly and only accepts moves based on the full log-ratio score. Prior feedback indicates the binding constraint is the denominator (|A+A|), not the numerator. This edit adds a targeted "sum-set compaction" move to `_local_search` that directly attacks |A+A|:

For a randomly chosen index i, we compute the base diff/sum sets once, then try candidate replacement values v in a small window around a[i] (say ±30). For each v we cheaply estimate the new sum set size as |base_sums ∪ {v + z : z in A\{a[i]}} ∪ {2v}| and the new diff set size similarly, then accept the v that minimizes |new_sums| subject to |new_diffs| >= 0.95 * |base_diffs|. This is O(window * n) per move instead of a full O(n^2) recompute per candidate, and it explicitly optimizes the denominator.

We integrate this as a new move branch in the existing random-move selection with a modest probability (~0.10), keeping the existing moves for exploration. When the compaction move is chosen, we perform the window scan, pick the best v, and use it as the candidate. This directly reduces |A+A| while preserving most of |A-A|, improving log|A-A|/log|A+A|.
</DESCRIPTION>
