<DESCRIPTION>
The current program only uses `_quadratic_set` (a Bose-Chowla-like Sidon construction) and `_greedy_sidon` with a very loose span (4*n^2), which makes |A+A| large. The prior "improved" version had a `_bounded_sidon` that constrains elements to a span near n^2, keeping the sum set compact while preserving Sidon-like properties (which maximize differences). It also had a `_reflect_half` heuristic and a multi-scale local search.

I will:
1. Add a `_bounded_sidon` function that greedily picks elements biased toward the center of a tight span, so that |A+A| stays small while |A-A| remains near maximal for a Sidon set.
2. Add a `_reflect_half` function that reflects the upper half of A around its center, which can compress the sum set.
3. Extend `solve()` to try bounded Sidon constructions over a range of sizes and spans, and use a multi-scale local search (alternating small and large step sizes) with occasional simulated-annealing-like acceptance, which explores the space more effectively.

The theoretical intuition: For a Sidon set A of size n, |A-A| = n^2 - n + 1 (maximal possible) and |A+A| = n(n+1)/2. If we additionally confine A to a tight interval, sums can collapse further (many coincident sums), boosting the ratio log|A-A|/log|A+A|. Bounded Sidon constructions from the prior version achieved 1.1373, better than what the current code likely produces.

def _bounded_sidon(n, span, seed=0):
    """Build a Sidon-like set of size n inside [0, span] using randomized greedy,
    biased toward keeping elements near the middle (compacting the sum set)."""
    rng = random.Random(seed)
    A = []
    used_sums = set()
    used_diffs = set()
    center = span // 2
    cand = sorted(range(0, span + 1), key=lambda x: (abs(x - center), rng.random()))
    for x in cand:
        ok = True
        new_sums = set()
        new_diffs = set()
        for a in A:
            s = x + a
            if s in used_sums or s in new_sums:
                ok = False
                break
            new_sums.add(s)
            d1 = x - a
            d2 = a - x
            if d1 in used_diffs or d2 in used_diffs or d1 in new_diffs or d2 in new_diffs:
                ok = False
                break
            new_diffs.add(d1)
            new_diffs.add(d2)
        if ok:
            A.append(x)
            used_sums |= new_sums | {2 * x}
            used_diffs |= new_diffs
        if len(A) >= n:
            break
    return A


def _reflect_half(A):
    """Reflect the upper half of A around its center to try to shrink |A+A|."""
    if len(A) < 4:
        return A
    B = sorted(A)
    c = (B[0] + B[-1]) // 2
    n = len(B)
    out = B[: n // 2] + [2 * c - x for x in B[n // 2:]]
    if len(set(out)) != len(B):
        return A
    return out
