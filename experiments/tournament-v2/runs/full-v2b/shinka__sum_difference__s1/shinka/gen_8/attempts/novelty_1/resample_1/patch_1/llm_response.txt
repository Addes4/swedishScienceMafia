<DESCRIPTION>
The current approach builds Sidon sets but doesn't explicitly optimize the sum set size. The key insight is that |A+A| can be reduced by making the set lie in a short arithmetic interval (compact range), while |A-A| stays large if differences are distinct.

Idea: 
1. Use Bose-Chowla quadratic Sidon sets but *shift* them so they're centered around 0, and then apply a "compaction" step that shrinks the spread while preserving uniqueness of differences. 
2. Better: build sets whose elements are all in a narrow range [L, L+M] with M small relative to n. For a Sidon set of size n, we need M >= n(n-1)/2 for distinct positive differences, but by allowing differences to repeat only in sign-symmetric ways, |A+A| can be much smaller.
3. Concretely, use a "half-Sidon" construction: A = {0,1,...,n-1} gives |A+A| = 2n-1 (minimal) but |A-A| = 2n-1 too, ratio 1. We need |A-A| large, so we want A to have many distinct *signed* differences while |A+A| stays O(n).
4. Key trick: choose A such that A+A is an interval of size ~c*n but A-A has size ~n^2/2. This requires A to be a "sum-bounded" set with distinct differences — essentially a Sidon set embedded in a short interval via a modular construction, then lifted.

Implementation: try the Bose-Chowla set {i + p*(i^2 mod p)} but then divide/scale to keep it compact, and additionally test variations where we take A = {a_i : i} with a_i = i*p + (i^2 mod p) but restricted to a subinterval, plus local search that specifically scores |A-A|/|A+A| and moves elements to reduce the sum set span.

Also add: for each candidate, try a "shift and reflect" — reflect half the elements around the center to potentially reduce |A+A| without changing |A-A|.

Finally, add a focused local search that uses the actual ratio and allows larger jumps, and try many random restarts with the best-scoring constructions as seeds.

def _bounded_sidon(n, span, seed=0):
    """Build a Sidon-like set of size n inside [0, span] using randomized greedy,
    biased toward keeping elements near the middle (compacting the sum set)."""
    rng = random.Random(seed)
    A = []
    used_sums = set()
    used_diffs = set()
    # Prefer candidates near the center of the span to keep |A+A| small.
    center = span // 2
    cand = sorted(range(0, span + 1), key=lambda x: (abs(x - center), rng.random()))
    for x in cand:
        ok = True
        new_sums = set()
        new_diffs = set()
        for a in A:
            s = x + a
            if s in used_sums or s in new_sums:
                ok = False
                break
            new_sums.add(s)
            d1 = x - a
            d2 = a - x
            if d1 in used_diffs or d2 in used_diffs or d1 in new_diffs or d2 in new_diffs:
                ok = False
                break
            new_diffs.add(d1)
            new_diffs.add(d2)
        if ok:
            A.append(x)
            used_sums |= new_sums | {2 * x}
            used_diffs |= new_diffs
        if len(A) >= n:
            break
    return A


def _reflect_half(A):
    """Reflect the upper half of A around its center to try to shrink |A+A|."""
    if len(A) < 4:
        return A
    B = sorted(A)
    c = (B[0] + B[-1]) // 2
    n = len(B)
    out = B[: n // 2] + [2 * c - x for x in B[n // 2:]]
    if len(set(out)) != len(B):
        return A
    return out
