<DESCRIPTION>
The bottleneck identified in prior generations is seed structure, not refinement. The current program relies on a single best seed for local search (Phase 2) and random structured restarts (Phase 3). This wastes the fact that `_reflect_half`-style transformations (negating/reflecting a subset of marks) preserve the difference-set size almost exactly while producing structurally distinct seeds with the same cardinality.

I add a `_reflect_marks` helper that reflects a subset of marks (the top fraction of marks above a center) around a chosen center. This is a cardinality-preserving, roughly difference-preserving transformation. After Phase 1 selects the top-K structured seeds, we generate 3-5 reflected variants per top seed (using multiple centers/fractions), keep only distinct-cardinality outputs, and feed each into `_local_search`. This gives genuine basin diversity at near-zero cost.

I also restructure Phase 1 to keep a top-K list of seeds (not just the single best) so reflected variants can be derived from several strong starting points, and I add the reflected variants into the restart pool in Phase 3.

Concretely:
- Add `_reflect_marks(a, center, frac)` helper.
- In Phase 1, collect a `top_seeds` list (top-8 distinct by score).
- After Phase 1, generate reflected variants of each top seed at centers {0.3, 0.4, 0.5, 0.6, 0.7} of the span and fractions {0.3, 0.4, 0.5} of the top marks; dedupe by cardinality; run `_local_search` on each within the remaining budget.
- In Phase 3, occasionally seed from a reflected variant of the current best instead of a fresh dense+Golomb construction.

This is a targeted, low-risk change: it only adds new seed-generation code paths and does not modify the objective or the core search operators.

def _reflect_marks(a, center, frac):
    """Reflect the top `frac` fraction of marks above `center` around `center`.

    This preserves cardinality and (approximately) the difference-set size
    while producing a structurally distinct seed.
    """
    a = sorted(set(a))
    n = len(a)
    if n < 2:
        return a[:]
    k = max(1, int(round(frac * n)))
    top = a[-k:]
    rest = a[:-k]
    reflected = [2 * center - x for x in top]
    out = sorted(set(rest + reflected))
    return out
