<DESCRIPTION>
The goal is to maximize log|A-A|/log|A+A|. This ratio is maximized when A is close to a Sidon set (all pairwise sums distinct, so |A+A| ≈ n(n+1)/2) while the difference set is as large as possible (ideally n(n-1) distinct nonzero differences). 

Key insights for improvement over the random baseline:
1. Structured construction beats random search. A classic strong family is the "greedy Sidon" / modular construction: take A = {2k*a + (k^2 mod p)} style sets, or use the Singer/Bose-Chowla style constructions. A simpler effective family is A = {i : i in [0,n)} ∪ {large*i + i^2} which gives many distinct differences.

2. A very effective practical family: take A = {x_i = i*M + (i*i mod p)} where M is large enough to separate residues, producing a near-Sidon set with n(n-1) distinct differences and only ~n(n+1)/2 sums.

3. I use a Bose-Chowla-like construction: pick a prime p, let n = p-1, and set A = {i : i mod (p-1)} combined with a quadratic residue offset. Concretely, use A = {i + p*(i*i mod p) : i in 0..p-1} — this yields distinct differences because the map i -> (i, i^2) mod p has the Sidon property (a+b=c+d implies {a,b}={c,d}).

4. Then locally improve: try several primes p, evaluate the actual score, and do a short simulated-annealing / hill-climb on the resulting set to squeeze out extra differences.

5. To keep |A+A| small while |A-A| large, we want the set to be Sidon (B_2 set) — the quadratic construction A = {i + p*i^2} gives a perfect B_2 set modulo p, hence distinct sums, while differences are also mostly distinct.

Implementation: generate candidates from the quadratic construction for many small primes, score them, pick the best, then run a short local search (perturb elements, accept if score improves). Return the best set found within the time budget.

The score function is computed efficiently using sets. For n up to ~200 this runs fast.

Let me implement:
- `_score(a)` same as before.
- `_quadratic_set(p)`: returns [i + p*(i*i % p) for i in range(p)] — a Sidon-like set of size p.
- Try p in a range, pick best.
- Then hill-climb with small perturbations.
- Return sorted set.

This should produce a much better ratio than the random baseline.

"""Improved: structured Sidon-like constructions + local search."""
import math
import random
import time


def _score(a):
    a = set(a)
    if len(a) < 2:
        return 0.0
    diffs = {x - y for x in a for y in a}
    sums = {x + y for x in a for y in a}
    if len(sums) == 0:
        return 0.0
    return math.log(len(diffs)) / math.log(len(sums)) + (1 - 1 / len(a)) / 100


def _quadratic_set(p):
    """Bose-Chowla-like Sidon set: A = {i + p*(i^2 mod p) : i in 0..p-1}."""
    return [i + p * ((i * i) % p) for i in range(p)]


def _greedy_sidon(n, seed=0):
    """Greedily build a Sidon set of size ~n within a bounded range."""
    rng = random.Random(seed)
    A = []
    used_sums = set()
    used_diffs = set()
    cand = list(range(1, 4 * n * n + 10))
    rng.shuffle(cand)
    for x in cand:
        ok = True
        new_sums = set()
        new_diffs = set()
        for a in A:
            s = x + a
            if s in used_sums or s in new_sums:
                ok = False
                break
            new_sums.add(s)
            d1 = x - a
            d2 = a - x
            if d1 in used_diffs or d2 in used_diffs or d1 in new_diffs or d2 in new_diffs:
                ok = False
                break
            new_diffs.add(d1)
            new_diffs.add(d2)
        if ok:
            A.append(x)
            used_sums |= new_sums | {2 * x}
            used_diffs |= new_diffs
        if len(A) >= n:
            break
    return A


def solve():
    """Return a list of distinct integers A making |A - A| large and |A + A| small."""
    best = None
    best_score = -1.0

    # Try structured quadratic constructions for a range of primes.
    primes = [p for p in range(11, 200) if all(p % d for d in range(2, int(p ** 0.5) + 1))]
    for p in primes:
        cand = _quadratic_set(p)
        s = _score(cand)
        if s > best_score:
            best_score = s
            best = cand[:]

    # Also try greedy Sidon sets of various sizes.
    for n in [30, 50, 80, 120, 150]:
        cand = _greedy_sidon(n, seed=n)
        if len(cand) >= 2:
            s = _score(cand)
            if s > best_score:
                best_score = s
                best = cand[:]

    if best is None:
        best = [7, 15, 18, 22, -3, -2]
        best_score = _score(best)

    # Local search: perturb elements, accept improvements.
    cur = best[:]
    cur_score = best_score
    deadline = time.time() + 100
    step = max(1, (max(cur) - min(cur)) // 50) if len(cur) > 1 else 1
    while time.time() < deadline:
        cand = cur[:]
        i = random.randrange(len(cand))
        delta = random.randint(-step, step)
        if delta == 0:
            delta = 1
        cand[i] += delta
        cand = list(set(cand))
        if len(cand) < 2:
            continue
        s = _score(cand)
        if s >= cur_score:
            cur, cur_score = cand, s
            if s > best_score:
                best, best_score = cand[:], s
        elif random.random() < 0.02:
            cur = cand

    return sorted(set(best))
