<DESCRIPTION>
The current program relies on random element perturbations in its final local search, which only weakly attacks the denominator |A+A| of the log-ratio. Prior feedback flags this as the binding constraint. I propose adding a targeted sum-set compaction move to the local-search loop: pick a random index i, compute the current difference set and sum set, then scan candidate replacement values v in a small window around a[i] and pick the v that minimizes |A+A| subject to keeping |A-A| at least 95% of its current size. This directly reduces the denominator while protecting the numerator, and is cheap since we maintain base_diffs/base_sums incrementally over the candidate window. I also add a periodic "compaction sweep" that iterates over all indices once with the same rule.

To implement this efficiently I compute the multiset contribution of each element to sums/diffs. For a candidate v replacing a[i], the new sum set is (base_sums minus sums involving a[i]) union {v + x for x in A\{a[i]}}. Since A is small (typically <= few hundred), a full recompute per candidate is acceptable within the 120s budget if we cap the window.

I add a helper `_sum_compaction_step(A, rng, window=30)` that performs one such move, and call it inside the final local-search loop with some probability, interleaved with the existing random perturbation. This keeps the existing exploration while adding a greedy descent on |A+A|.

The window size and the 0.95 floor are tunable; I set window=25 and floor=0.97 to be conservative so we do not degrade |A-A| too much. I also add a small trial count so the cost stays bounded.

The helper must be defined before `solve()` uses it. I add it just before `solve()`.

Additionally, I replace the existing final local-search block with a version that alternates random perturbation and `_sum_compaction_step`. The rest of the program is unchanged.

def _sum_compaction_step(A, rng, window=25, floor=0.97):
    """Pick a random index and try to replace a[i] with a nearby value that
    reduces |A+A| while keeping |A-A| >= floor * current |A-A|.
    Returns (new_A, new_score) or (A, _score(A)) if no improvement found."""
    if len(A) < 3:
        return A, _score(A)
    n = len(A)
    base_sums = {x + y for x in A for y in A}
    base_diffs = {x - y for x in A for y in A}
    base_size = len(base_diffs)
    best_A = A
    best_sums = len(base_sums)
    best_diffs = base_size
    i = rng.randrange(n)
    ai = A[i]
    others = A[:i] + A[i + 1:]
    # Precompute sums/diffs not involving a[i]
    others_set = set(others)
    sums_no_i = {x + y for x in others for y in others}
    diffs_no_i = {x - y for x in others for y in others}
    # Candidate values around a[i]
    candidates = [ai + d for d in range(-window, window + 1) if d != 0]
    rng.shuffle(candidates)
    # Always include the current value to allow early exit comparison
    for v in candidates:
        if v in others_set:
            continue
        new_sums = sums_no_i | {v + x for x in others} | {2 * v}
        new_diffs = diffs_no_i | {v - x for x in others} | {x - v for x in others}
        nd = len(new_diffs)
        if nd < floor * base_size:
            continue
        ns = len(new_sums)
        if ns < best_sums or (ns == best_sums and nd > best_diffs):
            best_sums = ns
            best_diffs = nd
            best_A = others + [v]
    if best_A is A:
        return A, _score(A)
    return best_A, _score(best_A)
