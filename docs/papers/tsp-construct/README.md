# Workshop paper: textbook heuristics beat LLM-designed step-by-step TSP heuristics inside their own interface

LaTeX source and PDF of the short paper written from
[experiments/tsp-construct-v1](../../../experiments/tsp-construct-v1/RESULTS.md). Every number in it
comes from that folder: `tables.md` and `summary.json`, the TSPLIB and reference checks in
`results/`, and the literature notes in `literature.md`. `numbers.tex` is generated by
`experiments/tsp-construct-v1/paper_numbers.py`.

Build with [Tectonic](https://tectonic-typesetting.github.io/):

```bash
cd docs/papers/tsp-construct && tectonic main.tex
```

`preamble.tex` is a copy of the shared preamble used by the team's other workshop drafts.
